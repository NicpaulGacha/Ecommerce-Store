# 🛍️ Modern E-Commerce Storefront

A sleek, responsive **React + Tailwind CSS** e-commerce app that fetches real product data from an external API.  
This project demonstrates front-end architecture, state management, and API integration — all essential skills for modern web apps.

## 🧱 Tech Stack

- ⚛️ **React (Vite)** — fast, modern build setup
- 🎨 **Tailwind CSS** — responsive and utility-first styling
- 🧭 **React Router DOM** — routing and dynamic pages
- 🧠 **Context API + useReducer** — global cart state management
- 🌐 **FakeStore API** — external data source for products
- 🚀 **Vercel / Netlify** — deployment

---

## ✨ Features

✅ Product grid with live data from API  
✅ Product details page (dynamic routing)  
✅ Add / Remove from cart (global state)  
✅ Cart page with totals  
✅ Responsive layout for all screen sizes  
✅ Clean, modular React structure  
✅ Ready for future upgrades (auth, filters, checkout)
